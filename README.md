# Portfolio — Rakesh D.R

> Professional Software Developer & Information Science Engineering student portfolio built with Next.js 16, React 19, TypeScript, Tailwind CSS, and Three.js.

## 🚀 Overview

- **Visual Architecture**: Strict editorial monochrome visual identity with deep charcoal black and high-contrast typography.
- **Hero Section**: 3D interactive wireframe depth scene built with Three.js with pointer lerp and motion sensitivity checks.
- **Curriculum Vitae**: In-website embedded PDF resume viewer modal without requiring downloads.
- **Case Studies**: Verified engineering projects including **SkillSwap** (peer-to-peer real-time communication via WebRTC) and **Wardrobe AI** (smart outfit recommendation engine).
- **Technical Skills**: Core competencies in C, C++, Java, Spring Boot, REST APIs, WebRTC, MySQL, Oracle, Data Structures & Algorithms, and Operating Systems.
- **My Soundtrack**: Official Spotify player integration featuring a custom Spotify theme, animated equalizer, and multi-track switcher.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **3D Graphics**: Three.js
- **Icons**: Lucide React & Custom SVG Vectors

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build

```bash
npm run build
npm start
```
